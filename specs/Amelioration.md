# Demande d'amélioration : nouvel utilisateur `Claude123`

> Entrée du prompt [04 · Workflow amélioration](../prompts/04-workflow-amelioration.md).

| Élément | Valeur |
|---|---|
| Type | Enhancement |
| Module | Login |
| Application | https://www.saucedemo.com/ |

## Description

Ajouter un nouvel utilisateur autorisé à se connecter à l'application :

- **Username :** `Claude123`
- **Password :** `secret_sauce`

## Critères d'acceptation

1. `Claude123` apparaît dans la liste des utilisateurs autorisés affichée sur la page de login.
2. La connexion avec `Claude123` / `secret_sauce` réussit sans message d'erreur.
3. L'utilisateur est redirigé vers `/inventory.html`.
4. La barre de navigation (logo, menu burger, panier) est visible.
